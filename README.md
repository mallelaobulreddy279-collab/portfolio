# Portfolio: Mallela Obul Reddy

Plain HTML, CSS and JavaScript. No build step, no backend.

## Run it
1. Open the `Portfolio` folder in VS Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also double-click `index.html` to open it in a browser.

## Edit it
- Replace `assets/images/profile.jpg` with your photo (square works best).
- Replace `assets/resume/Resume.pdf` to update the resume.
- Add project descriptions, GitHub and LinkedIn links in `index.html` (Projects and Contact sections).
